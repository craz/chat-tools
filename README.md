# Chat Tools

Personal **Chrome** (MV3) extension for [chatgpt.com](https://chatgpt.com/).

Quote replies, saved prompts, chat navigation, bookmarks, Markdown/PDF export, answer timestamps, collapse long answers, notes, chat tags, and more. Russian UI. Permission: `storage` only. Data stays in your browser.

## Install (unpacked)

1. Download **[chat-tools-0.3.10-share.zip](https://github.com/craz/chat-tools/releases/download/v0.3.10/chat-tools-0.3.10-share.zip)** from [Releases](https://github.com/craz/chat-tools/releases).
2. Unzip. Inside: folder `chat-tools` → `extension`.
3. Keep that folder somewhere permanent (e.g. Documents).
4. Chrome → `chrome://extensions` → enable **Developer mode** → **Load unpacked** → select the `extension` folder.
5. Pin Chat Tools from the puzzle menu. Open chatgpt.com (refresh if already open).

Do not move the folder after install — Chrome loads the extension from disk.

**Update:** replace the `extension` folder, click ↻ on the card in `chrome://extensions`, refresh chatgpt.com tabs.

## Features (short)

- Quote tools: Ask (native), reply immediately, clarify (basket), save to chat notes
- Prompts / templates with `{variables}` · Quick action chips
- Question rail · Answer bookmarks · Export MD/PDF · Save code as file
- Answer date/time · Collapse long answers · Chat length estimate
- Chat notes & tags · Settings backup · Thread width

Full install notes (Russian) are inside the zip (`README.md` / `README.txt`).

## Privacy

Only the `storage` permission. Works on chatgpt.com. Nothing is sent except messages you send yourself in ChatGPT. Answer times are read from the open chat on chatgpt.com the same way the page does (GET only).
